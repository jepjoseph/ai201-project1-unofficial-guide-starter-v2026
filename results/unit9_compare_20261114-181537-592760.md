## Limitations

- Fixed index and queries make repeated retrieval deterministic; latency varies with runtime conditions.
- Expected-phrase matching is a strict text proxy; paraphrases require manual review and generated answers are not scored here.
- Existing criteria for source naming, answer correctness and chunk integrity require separate verification.
- Hybrid constructs BM25 on each request, so these timings include that cost.
